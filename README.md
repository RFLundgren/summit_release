# Summit Releases

Windows release artifacts for Summit.

## Version 1.0.0

Files in this repository:
- `Summit_1.0.0_x64-setup.exe`
- `Summit_1.0.0_x64-setup.exe.sig`
- `Summit_1.0.0_arm64-setup.exe`
- `Summit_1.0.0_arm64-setup.exe.sig`
- `latest.json`

Install guide:
- Most Intel/AMD Windows PCs should use the `x64` installer.
- Windows on ARM devices should use the `arm64` installer.

`latest.json` is used by the Summit auto-updater to resolve the correct installer for each platform.
